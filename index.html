      📜・قوانين السيرفر

      أهلًا وسهلًا بالجميع! لضمان بيئة ممتعة ومحترمة لجميع الأعضاء، يُرجى الالتزام بالقوانين التالية.

      1・الاحترام المتبادل

      يُمنع السبّ المبالغ فيه، الإهانة الشخصية، العنصرية، التمييز، التحرش أو استهداف الأعضاء بقصد إزعاجهم.

      2・ممنوع السبام

      يُمنع تكرار الرسائل، إغراق الشات بالمنشنات، إرسال الرموز بكثرة أو استخدام الحروف الكبيرة بشكل مزعج.

      3・ممنوع الإعلانات دون إذن

      يُمنع الإعلان عن السيرفرات أو المشاريع أو الروابط الخاصة دون موافقة الإدارة، سواء في الشات أو الخاص أو عبر المنشنات.

      4・ممنوع استغلال الثغرات

      يُمنع نشر الثغرات التي تضر بالسيرفر أو استغلالها للإضرار بالأعضاء أو تجاوز أنظمة الحماية. يُرجى إبلاغ الإدارة عنها بشكل خاص.

      5・احترام الخصوصية

      يُمنع نشر المعلومات الشخصية أو المحادثات الخاصة أو الصور والتسجيلات دون موافقة أصحابها، كما يُمنع التهديد بنشرها.

      6・استخدام القنوات بشكل صحيح

      لكل قناة غرض محدد، لذا يُرجى إرسال الرسائل في مكانها المناسب والالتزام بموضوع القناة.

      7・ممنوع انتحال الشخصية

      يُمنع انتحال شخصية الإدارة أو أي عضو آخر، أو استخدام أسماء وصور بقصد التضليل أو الاحتيال.

      8・ممنوع إزعاج الإدارة

      يُرجى فتح تذكرة دعم عند الحاجة، وعدم تكرار المنشنات أو فتح تذاكر متعددة لنفس المشكلة دون داعٍ.

      9・الالتزام بتعليمات الإدارة

      يجب الالتزام بالتعليمات المتعلقة بتنظيم السيرفر والفعاليات، ويحق للإدارة التدخل عند وجود مخالفة، مع إمكانية مراجعة العقوبات عند تقديم اعتراض مناسب.

      10・ممنوع التحايل على العقوبات

      يُمنع استخدام الحسابات البديلة للتهرب من الحظر أو مواصلة المخالفات.

      11・ممنوع الاحتيال

      يُمنع خداع الأعضاء أو سرقة حساباتهم أو طلب كلمات المرور أو رموز التحقق أو استغلالهم بأي شكل.

      12・العقوبات

      تختلف العقوبة حسب نوع المخالفة وخطورتها وتكرارها، وقد تشمل التنبيه أو الإسكات أو الطرد أو الحظر.

      ملاحظة: دخولك إلى السيرفر يعني موافقتك على الالتزام بهذه القوانين. يُرجى احترام الجميع والمساهمة في جعل مجتمعنا مكانًا ممتعًا للجميع.
